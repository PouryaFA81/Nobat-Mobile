# راهنمای راه‌اندازی SMTP (نوبت موبایل)

نوبت موبایل ایمیل یادآوری را **از صندوق خودتان** می‌فرستد. میزبان، درگاه و ورود را در **حساب → اعلان‌ها → ایمیل (SMTP)** وارد کنید. چیزی از سرورهای ما رد نمی‌شود.

English: [SMTP setup guide](SMTP.md)

## چه چیزهایی لازم است

1. ایمیلی که مال شماست (جیمیل، اوت‌لوک، یاهو، ایمیل مطب و …)
2. تنظیمات **SMTP** همان سرویس
3. برای جیمیل/اوت‌لوک معمولاً **رمز برنامه** (نه رمز عادی ورود)

سپس در برنامه: **میزبان**، **درگاه**، **نام کاربری**، **رمز**، **فرستنده** را پر کنید → در صورت نیاز **استفاده از TLS** را روشن کنید → **ذخیره** → **ارسال آزمایشی**.

---

## جیمیل (رایج‌ترین)

گوگل دیگر رمز عادی حساب را برای SMTP قبول نمی‌کند. باید **رمز برنامه** بسازید.

1. [امنیت حساب گوگل](https://myaccount.google.com/security) را باز کنید
2. **تأیید دومرحله‌ای** را روشن کنید (الزامی است)
3. **App passwords / رمزهای برنامه** را پیدا کنید → برای Mail بسازید (نام مثلاً `Nobat Mobile`)
4. رمز ۱۶ نویسه‌ای را کپی کنید (فاصله‌ها مهم نیستند)

| فیلد در برنامه | مقدار |
|---|---|
| **میزبان** | `smtp.gmail.com` |
| **درگاه** | `587` |
| **استفاده از TLS** | روشن |
| **نام کاربری** | آدرس کامل جیمیل |
| **رمز** | **رمز برنامه** (نه رمز گوگل) |
| **فرستنده** | همان آدرس جیمیل |

**ارسال آزمایشی** را بزنید و صندوق گیرنده را چک کنید. اگر خطا دیدید، تأیید دومرحله‌ای و رمز برنامه را دوباره بررسی کنید.

## اوت‌لوک / Microsoft 365

| فیلد | مقدار |
|---|---|
| **میزبان** | `smtp.office365.com` |
| **درگاه** | `587` |
| **استفاده از TLS** | روشن |
| **نام کاربری** | آدرس کامل ایمیل |
| **رمز** | رمز حساب، یا [رمز برنامه](https://account.microsoft.com/security) اگر ۲FA دارید |
| **فرستنده** | همان آدرس |

بعضی حساب‌های سازمانی SMTP را می‌بندند — در صورت خطا با IT حرف بزنید.

## سایر سرویس‌ها (ایمیل مطب / اختصاصی)

از ارائه‌دهنده «SMTP outgoing» بپرسید و این‌طور پر کنید:

| فیلد برنامه | معمولاً یعنی |
|---|---|
| **میزبان** | نام سرور SMTP (مثلاً `mail.yourclinic.com`) |
| **درگاه** | اغلب `587` (TLS) یا `465` (SSL) |
| **استفاده از TLS** | برای ۵۸۷ روشن؛ برای ۴۶۵ طبق راهنمای ارائه‌دهنده |
| **نام کاربری** | اغلب آدرس کامل ایمیل |
| **رمز** | رمز صندوق یا رمز برنامه |
| **فرستنده** | آدرسی که گیرنده می‌بیند |

---

## نکته‌ها

- **میزبان / درگاه / فرستنده** حتی در رابط فارسی چپ‌به‌راست می‌مانند.
- قبل از اتکا به یادآوری‌ها، حتماً **ارسال آزمایشی** کنید.
- رمز فقط **روی همین گوشی** و برای همان حساب محلی ذخیره می‌شود.
- پیامک جداست: **ارسال با گوشی** اپ SMS گوشی را باز می‌کند؛ SMTP لازم نیست.

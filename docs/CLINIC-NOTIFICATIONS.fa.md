# راهنمای اعلان‌های مطب (نوبت موبایل)

پرسنل برای نوبت‌های اختصاص‌داده‌شده به خودشان **داخل برنامه** اعلان می‌گیرند. زیر ساخت، اپ از یک موضوع اعلان روی **همان** میزبان ntfy شما استفاده می‌کند — در رابط کاربری هرگز «ntfy» نوشته نمی‌شود. پرسنل فقط **کد مطب** و **اعلان‌های مطب · متصل** را می‌بینند.

English: [Clinic notifications setup](CLINIC-NOTIFICATIONS.md)

## مهم — نصب نوبت دوستتان

اگر نوبت (PWA) با ntfy برای دوستتان بالا است:

- **Compose دوم** یا زیردامنهٔ جدید نسازید  
- Compose، پورت، TLS یا موضوع‌های مشترکشان را عوض نکنید  
- فقط یک **موضوع جدید** (و در صورت نیاز توکن محدود به همان موضوع) روی **همان** ntfy بسازید  

موضوع‌های قبلی دست نخورده می‌مانند. موبایل فقط روی موضوع جدید کار می‌کند.

---

## چه چیزهایی لازم است

1. آدرس پایهٔ ntfy (معمولاً `https://ntfy.yourdomain` روی ۴۴۳)  
2. نام **موضوع جدید** فقط برای موبایل، مثلاً `nobat-mobile-clinic1`  
3. در صورت ACL، **توکن**ی که فقط همان موضوع را بخواند/بنویسد  

کد مطب در برنامه = آدرس پایه + موضوع + توکن (در یک رشتهٔ قابل اشتراک).

---

## ۱. موضوع اختصاصی (+ توکن)

روی **همان** کانتینر ntfy (نمونه — با CLI ایمیج خودتان جور کنید):

```bash
ntfy token add --expires=never
ntfy access <user-or-token> nobat-mobile-clinic1 read-write
```

اگر احراز هویت اجازهٔ هر موضوعی را می‌دهد، فقط یک **نام موضوع تازه** که PWA استفاده نمی‌کند کافی است.

---

## ۲. گوشی مدیر (نوبت موبایل)

1. **حساب → تنظیمات پیشرفته → کد مطب**  
2. **رله** (پیشرفته): آدرس · موضوع · توکن — یا **کد مطب** ترکیبی را بسازید/به اشتراک بگذارید  
3. وضعیت: **اعلان‌های مطب · متصل**  
4. کد را با پرسنل به اشتراک بگذارید؛ در صورت لو رفتن **بازتولید** کنید  

با **اختصاص به** هنگام ثبت یا لغو، گوشی مدیر روی موضوع منتشر می‌کند؛ گوشی‌های پرسنل اعلان محلی می‌بینند.

---

## ۳. گوشی پرسنل

1. همان APK نوبت موبایل را نصب کنید  
2. نقش = **پرسنل**، **پیوند به پرسنل**  
3. **ورود کد مطب** → **اتصال**  
4. وضعیت: **اعلان‌های مطب · متصل**  

اعلان‌ها برای **نوبت‌های خودشان** است. SMTP / تلگرام / پیامک اختیاری می‌مانند.

---

## پایداری

با بسته بودن اپ یا Doze، فقط گوش‌دادن HTTP ممکن است دیر برسد. برای جیب، در صورت امکان FCM روی رله را روشن کنید. تبلت روشن در مطب معمولاً کافی است.

## VPS ایران بدون پورت ۴۴۳

به‌صورت `https://host:8443` داخل کد مطب ممکن است، ولی بعضی شبکه‌ها پورت غیر ۴۴۳ را می‌بندند. برای گوشی پرسنل ترجیحاً ntfy دوستتان روی **۴۴۳**.
